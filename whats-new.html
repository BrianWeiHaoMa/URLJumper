What's new in URLJumper 2.0

Your mappings, your theme, and your shortcuts are as you left them, and the popup lists your mappings in the order it always has. Here is what is new.

  • A name typed in full comes first

    The mapping whose name is exactly what you typed is listed first, even when an earlier line's name starts with it: with mailbox above mail, typing mail lists mail first.

  • Search through a name with %s

    Put %s in a mapping's URL, and the text you type after its name goes there. With the line yt https://www.youtube.com/results?search_query=%s, typing yt lo-fi beats and Enter searches YouTube for lo-fi beats; yt alone opens the URL with %s left empty.

  • Name this page

    Give the page you are on a name, and next time type that name to return to it. Use the Name this page shortcut, suggested as Alt+Shift+N; where something else already uses that key, Chrome leaves the shortcut unassigned, and Chrome's shortcuts page (chrome://extensions/shortcuts) shows the key it has and lets you choose one. Or right-click a page and choose Name this page in URLJumper, or a link and choose Name this link in URLJumper. And when what you type in the popup matches no name, its last row offers to name the page you are on with it.

  • The keyword j in the address bar

    In Chrome's address bar, type j, a space, and a name: Chrome suggests your mappings, in the order the popup lists them, and Enter opens one.

  • Smart order

    Smart order lists the mappings you used recently first. It is off for you, so your list keeps the order of your document. To turn it on, choose Smart order in Preferences, in the popup's settings (the gear) or on the settings page.
